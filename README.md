# Karthickraja K — Portfolio Website

A responsive, modern dark-themed personal portfolio built with plain HTML, CSS and JavaScript. No framework or build tools are required.

## 1. Run locally in VS Code

1. Download and extract `karthickraja-portfolio.zip`.
2. Open the extracted `karthickraja-portfolio` folder in Visual Studio Code.
3. Install the **Live Server** extension (by Ritwick Dey).
4. Right-click `index.html` and choose **Open with Live Server**.
5. Your browser should open the site, usually at `http://127.0.0.1:5500`.

You can also open `index.html` directly in a browser, but Live Server is more convenient while editing.

## 2. Personalize before publishing

Search the project for `TODO` and replace the placeholders.

- `your.email@example.com` — replace with your real email in `index.html` and `script.js`.
- LinkedIn URL — replace `https://www.linkedin.com/` with your profile URL.
- GitHub URL — replace `https://github.com/` with your GitHub profile and each project repository URL.
- Resume — add your PDF to `assets/` (for example `assets/Karthickraja_Resume.pdf`) and add a link in the hero or contact section:
  `<a class="button button-secondary" href="assets/Karthickraja_Resume.pdf" target="_blank">View resume</a>`
- Project details — update descriptions, technologies, status and links to match what you have actually built.
- Education — verify degree titles, college names, years and any grades before publishing.
- Skills — keep only technologies you can confidently explain in an interview.
- Certification — add the training provider, date and certificate URL if available.

Do not publish private information such as your home address, personal ID numbers or phone number unless you intentionally want it public.

## 3. Deploy free with GitHub Pages

1. Create or sign in to a GitHub account.
2. Create a new public repository, for example `karthickraja-portfolio`.
3. Upload `index.html`, `style.css`, `script.js`, `README.md` and the `assets` folder to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for the Pages deployment to finish. Your site will be available at:
   `https://YOUR-GITHUB-USERNAME.github.io/karthickraja-portfolio/`

If you name the repository `YOUR-GITHUB-USERNAME.github.io`, the site can instead use that root URL.

## 4. Deploy with Netlify (alternative)

1. Visit https://www.netlify.com/ and sign in.
2. Choose **Add new site → Import an existing project**.
3. Connect GitHub and select your portfolio repository.
4. Leave the build command and publish directory blank (or use `.` as the publish directory).
5. Deploy. Netlify will provide a public URL.

## 5. Before sending the link to recruiters

- Test the site on a phone and desktop.
- Click every navigation, email, GitHub and LinkedIn link.
- Confirm your project descriptions are accurate and repositories are public.
- Add your real resume PDF.
- Check spelling, education details and dates.
- Do not claim a project is complete if it is still in progress.
